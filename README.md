# Utsav Bhatt — Finance & Research Portfolio

A personal portfolio presenting selected work across financial research, quantitative analysis, financial modelling, technical tools and communication.

**Live site:** https://utsavbhatt.github.io/MyPortfolio/  
**Repository:** https://github.com/UtsavBhatt/MyPortfolio

## What this portfolio demonstrates

The work is organised around four capabilities:

1. **Research & Analytics** — company analysis, fixed-income research and empirical work on FX options.
2. **Technical Skills** — Excel modelling, Python-based analysis and financial data processing.
3. **Concepts & Theory Knowledge** — integrated financial statements, valuation, derivatives and explainable machine learning in credit risk.
4. **Communication & Stakeholder Management** — selected examples of presenting, hosting and communicating with different audiences.

Projects are assigned one primary home rather than repeated across categories. Individual project pages contain the relevant write-up, visual evidence and downloadable files or external notebooks.

## Site structure

- `index.md` — homepage and four capability links.
- `_pages/projects.md` — work directory and category sections.
- `_pages/about.md` — background, experience and education.
- `_pages/*.md` — individual project and communication pages.
- `assets/files/` — downloadable reports and workbooks.
- `assets/images/` — profile and communication photographs.
- `assets/css/main.scss` — typography, colour system, layout and responsive styling.
- `_data/navigation.yml` — top navigation.
- `_config.yml` — Jekyll and Minimal Mistakes configuration.

## Built with

## Local preview

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve`.
4. Open the local address printed by Jekyll.

The configured base URL is `/MyPortfolio`; use the URL generated by Jekyll for local testing.

## Updating the portfolio

- Add downloadable work to `assets/files/`.
- Add photographs and project visuals to `assets/images/`.
- Create or update the relevant page in `_pages/`.
- Add each project to its single primary category in `_pages/projects.md`.
- Check file names, page links and download paths before merging.
- Check GitHub Actions after merging to confirm deployment.
