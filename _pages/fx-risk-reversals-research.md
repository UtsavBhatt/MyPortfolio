# FX Options as Macro Risk Indicators

Tests whether USD/INR 25-delta risk reversals contain information about subsequent spot-market stress, using event windows and lead–lag tests on 2018–2025 derivatives data.
<img width="1177" height="615" alt="image" src="https://github.com/user-attachments/assets/5cd403ac-ba75-4dbf-b054-ef9e87679f8f" />


**Reported result:** strongest lead–lag result at a three-day lag (p = 0.009); observational, not proof of causality or predictive performance.



Created a custom dataset by combining multiple data sources for this analysis and Open sourced it on Kaggle.
