# WayneTech — From Transactions to Financial Statements

This workbook follows an accounting workflow from a raw transaction register to classified data, financial statements and forecasts. It covers historical statements for FY24–FY26 and forecast years FY27–FY29.

## How the model is organised

**1. Source transactions**

The transaction register provides the underlying entries used in the model.
