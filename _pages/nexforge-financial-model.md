# NexForge Manufacturing — Three-Statement Model & DCF

An interview-style manufacturing case built from historical financial statements for 2022–2024 and forecast assumptions for 2025–2027. The model links the three statements, derives unlevered free cash flow and applies a discounted cash flow valuation.

## Model output

The submitted model produced an enterprise value of **US$879m**, an equity value of **US$840m** and an implied value of **US$42 per share**. These are outputs from the exercise, not an independently verified valuation.
